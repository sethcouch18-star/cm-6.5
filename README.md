# Colormons 6.0 (Cobblemon 1.8.1, NeoForge 1.21.1)

Look at a Pokemon and press C.

- Preview shows the real 3D model, slowly turning.
- Hover a group row: the group map lights that group and dims the rest.
- Edit on -> pick a group -> click the grid to paint those pixels into that group.
- Finishes: Default, Glossy, Matte, Shiny.
- Colours are shared with other players when the server has the mod.

No ownership check: painting works on any Pokemon you look at.
The rule about not painting other people's Pokemon is a server rule, not enforced here.

Config: config/colormons.json
Masks: assets/colormons/masks/<species>.png
  red = Primary, green = Secondary, blue = Tertiary, yellow = Custom.
